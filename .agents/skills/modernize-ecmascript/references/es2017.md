  该提案为 ECMAScript 添加了共享内存和原子操作，支持在 JavaScript 中进行高性能并发编程。Firefox、Chrome 和 WebKit 中提供了原型实现，但启用配置有所不同。

- [Trailing commas in function parameter lists and calls（函数参数列表和调用中允许尾随逗号的提案）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-trailing-function-commas.md) — Stage 4 · 已完成
  该提案解决了在多行函数定义或调用中添加参数时需要修改前一行（添加逗号）并添加新行，从而影响版本控制 blame 信息的问题。解决方案是允许在函数参数列表和调用中使用尾随逗号，与其他语言的功能一致。
