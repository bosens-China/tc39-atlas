- [Float16 on TypedArrays, DataView, Math.f16round（Float16Array：在 TypedArrays、DataView 和 Math.f16round 中支持半精度浮点数）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-float16array.md) — Stage 4 · 已完成
  该提案为 JavaScript 添加 Float16Array 类型化数组、DataView 的 getFloat16/setFloat16 方法以及 Math.f16round，以支持半精度浮点数。它旨在解决 canvas 颜色、GPU 操作、WebGL 和 WebGPU 中不需要全精度且内存有限的用例。

- [Import Attributes（导入属性）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-import-attributes.md) — Stage 4 · 已完成
  导入属性提案为模块导入语句添加内联语法，用于在模块说明符之外传递元数据，从而以标准化方式支持其他模块类型（如 JSON 模块）。它引入了 `with` 关键字后跟键值列表，例如 `import json from "./foo.json" with { type: "json" };`，并应用于静态导入、重导出、动态 `import()` 以及 worker 等宿主环境。

- [Intl.DurationFormat（Intl.DurationFormat 提案）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-intl-duration-format.md) — Stage 4 · 已完成
  该提案引入了 Intl.DurationFormat，这是一个新的 Intl API，用于对时间持续时间进行区域设置感知的格式化。它支持多个持续时间单位、格式化宽度（长、短、窄、数字）、按单位的样式/显示选项以及亚秒小数的显示。

- [JSON Modules（JSON 模块）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-json-modules.md) — Stage 4 · 已完成
  该提案通过利用带有 `type: "json"` 的导入属性，标准化了跨 JavaScript 环境的 JSON 模块导入。它通过在导入位置要求显式属性来解决意外 MIME 类型的安全问题，同时允许宿主定义额外的检查。

- [New Set methods（新的 Set 方法）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-set-methods.md) — Stage 4 · 已完成
  该提案为 JavaScript 内置的 Set 原型添加了像 union、intersection 和 difference 等集合操作方法，解决了无需第三方库即可进行常见集合操作的需求。它规定了七个方法，所有方法都要求参数具有数值 size 属性以及 keys 和 has 方法。

- [Promise.try](https://bosens-china.github.io/tc39-atlas/proposals/proposal-promise-try.md) — Stage 4 · 已完成
  该提案引入了 Promise.try，一个调用函数并返回 promise 的方法，通过 promise 语义处理同步返回值或抛出的异常。它避免了 Promise.resolve().then(f) 的额外微任务延迟，镜像了 async function 到第一个 await 的执行。

- [Redeclarable global eval-introduced vars（可重新声明的全局 eval 引入的变量）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-redeclarable-global-eval-vars.md) — Stage 4 · 已完成
  该提案通过消除 eval 引入的全局 var 绑定与其他全局属性之间的区别，简化了 ECMAScript，允许在全局顶层对 eval 引入的 var 进行词法重新声明。它移除了全局环境记录中的 \[\[VarNames\]\] 跟踪，将重新声明错误的情况从三种减少为两种。

- [RegExp Modifiers（正则表达式修饰符）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-regexp-modifiers.md) — Stage 4 · 已完成
  该提案为 ECMAScript 正则表达式引入了模式修饰符，允许在子表达式中使用诸如 `(?imsx-imsx:子表达式)` 的语法切换 `i`、`m`、`s` 和 `x` 等标志。它解决了在无法执行代码的上下文（如配置文件）中控制正则表达式标志的需求。

- [RegExp.escape](https://bosens-china.github.io/tc39-atlas/proposals/proposal-regex-escaping.md) — Stage 4 · 已完成
  该提案引入了一个静态的 `RegExp.escape` 函数，用于转义字符串以便在正则表达式中字面使用，解决了避免特殊字符被解释为正则表达式的常见需求。该提案也探索了模板标签的替代方案，但拒绝了它，而选择了更简单的函数，该函数被广泛需求并在许多其他语言中实现。

- [Sync Iterator helpers（同步迭代器辅助方法）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-iterator-helpers.md) — Stage 4 · 已完成
  该提案向 ECMAScript 中的 Iterator 原型添加一组辅助方法，如 map、filter、take、drop、flatMap、reduce、toArray、forEach、some、every 和 find，以及一个静态的 Iterator.from 方法。它旨在使迭代器像数组一样易于使用，并解决常见的使用模式。
