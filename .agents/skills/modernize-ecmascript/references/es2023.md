- [Array find from last（数组从末尾开始查找）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-array-find-from-last.md) — Stage 4 · 已完成
  该提案为数组和类型化数组的原型添加了 `findLast()` 和 `findLastIndex()` 方法，允许开发者根据条件从数组末尾向前查找元素或其索引。它解决了迭代向后但不需变更或复杂索引计算的需求，而这些是 `\[.arr\].reverse().find()` 等变通方法所必需的。

- [Change Array by Copy（通过复制更改数组）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-change-array-by-copy.md) — Stage 4 · 已完成
  此提案为 Array.prototype 和 TypedArray.prototype 添加了非变异数组方法，例如 toReversed、toSorted、toSpliced 和 with，这些方法返回应用更改后的新副本。其目的是支持不可变风格的编程以及与元组的互操作性。

- [Hashbang Grammar（Hashbang 语法）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-hashbang.md) — Stage 4 · 已完成
  该提案通过在 JS 引擎中处理 hashbang（#!）注释的剥离，而不再由 CLI 宿主处理，从而标准化了源文件开头的 hashbang 语法。它仅在 Script 或 Module 目标的开头允许 hashbang，支持 eval 但不支持 Function，并处理了 BOM 的交互。

- [Intl.NumberFormat V3](https://bosens-china.github.io/tc39-atlas/proposals/proposal-intl-numberformat-v3.md) — Stage 4 · 已完成
  该提案通过添加范围格式化、基于枚举的分组选项、新的舍入和精度控制、对十进制字符串的支持、额外的舍入模式以及新的 signDisplay 值来增强 Intl.NumberFormat。它旨在满足常见的客户端需求，并借鉴了 CLDR/ICU 中的现有实践。4、Chrome 106 和 Firefox 93 中发布。

- [Symbols as WeakMap keys（Symbols 作为 WeakMap 键）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-symbols-as-weakmap-keys.md) — Stage 4 · 已完成
  该提案扩展了 WeakMap，允许使用唯一的 Symbol 作为键，解决了仅能将对象作为键的限制。它支持了更轻松的键创建、ShadowRealms 中基于膜的虚拟化以及从 Records 和 Tuples 引用对象等用例。
