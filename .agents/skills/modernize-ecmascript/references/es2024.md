- [Array Grouping（数组分组）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-array-grouping.md) — Stage 4 · 已完成
  该提案解决了按键对数组元素进行分组的常见需求，提供了两个静态方法：Object.groupBy 用于普通对象和 Map.groupBy 用于对象作为键。该设计避免了 Array.prototype 方法的 Web 兼容性问题，并支持未来的 Records 和 Tuples。

- [ArrayBuffer transfer（ArrayBuffer 转移）](https://bosens-china.github.io/tc39-atlas/proposals/arraybuffer-transfer.md) — Stage 4 · 已完成
  该提案向 `ArrayBuffer.prototype` 添加了 `transfer`、`transferToFixedLength` 和 `detached` getter，使得 ArrayBuffer 的程序化分离和所有权转移成为可能。该 API 支持所有权语义、类似 realloc 的大小调整、将可调整大小的缓冲区固定为固定长度以及权威的分离状态检查等使用场景。

- [Atomics.waitAsync（Atomics.waitAsync（异步原子等待））](https://bosens-china.github.io/tc39-atlas/proposals/proposal-atomics-wait-async.md) — Stage 4 · 已完成
  该提案引入了 Atomics.waitAsync，是 Atomics.wait 的异步版本，适用于不允许阻塞的环境。它提供了一种在共享内存上等待而不阻塞代理的方式，返回类似 Promise 的结果。该提案目前处于早期阶段，有历史文档可供参考，但主要提案文本仍在演进中。

- [Promise.withResolvers](https://bosens-china.github.io/tc39-atlas/proposals/proposal-promise-with-resolvers.md) — Stage 4 · 已完成
  该提案解决了手动创建 Promise 时提取 resolve 和 reject 函数所需的样板代码问题。它添加了一个静态方法 `Promise.withResolvers()`，返回包含 promise 及其 resolve/reject 函数的对象。

- [RegExp v flag with set notation + properties of strings（带有集合表示法和字符串属性的 RegExp `v` 标志）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-regexp-v-flag.md) — Stage 4 · 已完成
  该提案为 ECMAScript 正则表达式添加了一个新的 `v` 标志，支持集合表示法，如差集（`A--B`）、交集（`A&&B`）和嵌套字符类，以及字符类中的字符串属性和字符串字面量。它解决了对表现力丰富的字符类组合和 Unicode 字符串属性的需求，改进了现有 `u` 标志的有限语法和不区分大小写匹配。

- [Resizable and growable ArrayBuffers（可调整大小和可增长的 ArrayBuffer）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-resizablearraybuffer.md) — Stage 4 · 已完成
  该提案扩展了 ArrayBuffer 和 SharedArrayBuffer 构造函数，使其接受可选的​​最大长度，从而实现原地调整大小（针对 ArrayBuffer）或增长（针对 SharedArrayBuffer）。由这些缓冲区支持的 TypedArray 可以自动跟踪长度，或在越界时表现出类似已分离的行为。

- [Well-Formed Unicode Strings（良构 Unicode 字符串）](https://bosens-china.github.io/tc39-atlas/proposals/proposal-is-usv-string.md) — Stage 4 · 已完成
  该提案解决了验证 JavaScript 字符串是否为良构 UTF-16 的问题，这是与基于 Unicode 的 API 接口所必需的。它添加了两个方法，`String.prototype.isWellFormed` 和 `String.prototype.toWellFormed`，分别用于测试和转换字符串。
