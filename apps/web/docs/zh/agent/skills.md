# 使用 Skills

TC39 Atlas 仓库内包含项目维护使用的 Agent Skills。运行以下命令，让 Skills CLI 从当前仓库发现并安装它们：

```bash
npx skills add https://github.com/bosens-China/tc39-atlas
```

安装过程中按命令行提示选择需要的 Skill 和目标 Agent。完成后重新打开对应 Agent 会话，使新 Skill 生效。

:::tip 更新 Skills
仓库中的 Skill 发生变化后，重新运行同一条命令即可进入更新流程。
:::
