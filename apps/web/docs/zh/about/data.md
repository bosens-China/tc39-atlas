# 数据来源与更新

TC39 Atlas 每天通过 GitHub Actions 读取 [TC39 Dataset](https://tc39.es/dataset/) 和各提案的 GitHub README。结构化状态以 TC39 官方数据为准，正文以提案仓库为准。

网站使用带版本清单与 SHA-256 校验的 JSON 数据集。一次同步或构建失败不会覆盖上一份已经发布的数据。

数据集的“日更批次”使用 `Asia/Shanghai` 日历日期，是变化页滚动窗口的稳定锚点；“检查时间”表示最近一次成功获取并比较官方数据的实际时间。变化页中的“检测时间”表示本站首次在每日快照比较中发现变化的时间，不代表 TC39 官方实际修改的精确时刻。

定时任务和显式手动同步会推进日更批次。普通代码 push、Pull Request CI 和网站重复构建只使用已经提交的数据，不会移动统计范围。日变化比较上一次成功批次与当前批次，其他入口分别展示近 7 日、近 1 个月、近 3 个月和近 1 年的变化。
