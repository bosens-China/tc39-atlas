# 关于 TC39 Atlas

TC39 Atlas 面向关注 ECMAScript 演进的中文读者与 AI Agent，每天同步 TC39 提案、中文 README 译文和阶段变化。

网站、Skills 和 MCP 围绕同一目标组织：让人和 Agent 都能从稳定链接找到提案，并随时回到 TC39 官方数据与原始仓库核对。

:::info 项目边界
TC39 Atlas 不替代 TC39 规范、提案仓库或官方状态。中文内容仅用于辅助阅读。
:::
