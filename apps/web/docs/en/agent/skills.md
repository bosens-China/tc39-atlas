# Use Skills

The TC39 Atlas repository contains Agent Skills used to maintain the project. Let the Skills CLI discover and install them from this repository:

```bash
npx skills add https://github.com/bosens-China/tc39-atlas
```

Follow the CLI prompts to select the Skills and target agent you need. Start a new agent session after installation so the Skills are loaded.

:::tip Update Skills
Run the same command again when the repository Skills change.
:::
