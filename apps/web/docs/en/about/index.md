# About TC39 Atlas

TC39 Atlas serves ECMAScript readers and AI agents with daily-synchronized TC39 proposals, Chinese README translations, and stage changes.

The website, Skills, and MCP share one goal: give people and agents stable proposal links while keeping the official TC39 data and source repositories one click away.

:::info Project boundary
TC39 Atlas does not replace TC39 specifications, proposal repositories, or official status. Translations are reading aids only.
:::
