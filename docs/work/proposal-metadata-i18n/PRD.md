# 提案元数据双语化

## 背景与目标

当前中文站已展示中文 README，但提案标题仍与英文站相同。此次为提案增加独立的中文标题，并让后续 GitHub Actions 使用 OpenAI SDK 自动补齐新增或变更提案的标题翻译。

## 范围与非目标

- 为数据集增加中文标题及其翻译元数据。
- 本次现有提案的中文标题由 Codex 生成并作为人工种子提交。
- 后续 CI 使用 OpenAI Responses API 和结构化输出翻译种子未覆盖的标题。
- 中文列表、详情页、搜索和页面描述使用中文标题；英文站继续使用 TC39 官方英文标题。
- 页面描述使用确定性模板，不让模型凭空生成提案摘要。
- README 翻译继续沿用现有独立流程。

## 已确认需求与决策

- 官方英文标题始终保留为权威字段 `title`，中文标题使用可回退字段 `titleZh`。
- 人工标题种子以英文原文为键；原文变化后自动失效并进入 CI 翻译队列。
- 标题翻译与 README 翻译分别记录源哈希，避免两类内容互相导致无意义重译。
- 未配置 API Key 或单项翻译失败时继续发布英文数据，并以英文标题作为中文站回退。

## 验收标准

- 当前数据集中所有提案都有非空中文标题。
- 中文和英文提案列表、详情标题、页面描述及搜索结果具有正确语言差异。
- 新增或标题变化的提案可由 CI 通过 OpenAI SDK 补齐中文标题。
- 数据模型、翻译、查询和文档生成测试通过。
- GitHub Pages 生产工作流成功，线上中英文页面可直接访问。

## 文档与兼容性影响

- 数据集 Schema 版本升级，MCP 会下载并校验新版本。
- README 和现行 PRD需补充双语标题与 CI 翻译行为。
